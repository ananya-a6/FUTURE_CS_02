# # FUTURE_CS_02

## Phishing Email Detection & Awareness System

### Objective
Analyze phishing email samples and identify phishing indicators to improve security awareness.

### Tools Used
- Google Message Header Analyzer
- MXToolbox Header Analyzer
- Browser Tools
- GitHub Sample Repositories

### Analysis Approach
- Email content inspection
- Sender verification
- URL analysis
- Risk classification
- User awareness recommendations

### Findings Summary

| ID | Finding | Risk |
|----|----------|------|
| P-01 | Suspicious Sender Domain | High |
| P-02 | Urgency/Fear-Based Language | Medium |
| P-03 | Suspicious URL | High |
| P-04 | Generic Greeting | Medium |

### Repository Structure

- Evidence → Screenshots and analysis
- Report → Final awareness report
- README.md → Project overview
