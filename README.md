# FUTURE_CS_02

## Phishing Email Detection & Awareness System

### Objective

The objective of this project is to analyze phishing email samples, identify phishing indicators, classify email risks, and create awareness guidelines that help users recognize and avoid phishing attacks.

### Target

Sample Phishing Email Analysis

### Assessment Type

Phishing Email Detection and Security Awareness Assessment

### Tools Used

* Public Phishing Email Samples
* Browser-Based URL Inspection
* GitHub
* Markdown Documentation

### Analysis Approach

1. Collected a phishing email sample.
2. Examined the sender address and email content.
3. Inspected the embedded URL for suspicious behavior.
4. Identified phishing indicators.
5. Classified the overall email risk level.
6. Documented findings and awareness recommendations.

## Findings Summary

| ID   | Finding                         | Risk   |
| ---- | ------------------------------- | ------ |
| P-01 | Suspicious Sender Domain        | High   |
| P-02 | Urgency and Fear-Based Language | High   |
| P-03 | Suspicious Verification Link    | High   |
| P-04 | Generic Greeting Used           | Medium |
| P-05 | Account Suspension Threat       | High   |

### Risk Classification

**Overall Risk Level: High**

### Key Findings

* The sender domain is not associated with a trusted organization.
* The email uses urgency tactics to pressure the recipient.
* The verification URL appears suspicious and untrusted.
* The message uses a generic greeting rather than the recipient's name.
* Fear-based language is used to encourage immediate action.
* URL inspection resulted in a Cloudflare Error 522, indicating the website is unavailable or improperly configured.

### Repository Structure

* Evidence → Email samples, screenshots, and analysis findings.
* Report → Final phishing detection and awareness report.
* README.md → Project overview and findings summary.
